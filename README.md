# ADAM AI & Creator Pro

Adam is a Python-based software suite that allows you to create a customized avatar ("Adam Creator Pro") and interact with it vocally in real-time ("Adam AI").

The application integrates advanced cloud and local AI techniques: speech synthesis (Edge-TTS), speech recognition (Whisper via Groq), Voice Activity Detection (Silero VAD), and a high-performance LLM (Llama 3 via Groq) to provide a highly responsive virtual assistant with real-time lip-syncing.

---

## Project Structure

The project is divided into two independent modules. You can choose to install only the lightweight graphical Editor, or the full Runtime suite.

### Adam Creator Pro (Editor)

A graphical user interface developed with `tkinter` and `PIL` to visually design and customize your avatar. It allows you to import custom prompts, select voice gender and language, and exports a complete profile in `.json` format.

### Adam AI (Runtime)

The execution environment that loads the profile generated by the editor. It listens to the user via the microphone, transcribes the audio using Groq, processes a response through the Groq LLM, and plays it back using Edge-TTS, dynamically animating the avatar's mouth based on audio volume and phonemes.

## System Requirements

### For the Editor (Adam Creator Pro)

* Python 3.9+
* Pillow, Tkinter

### For the Runtime (Adam AI)

* Python 3.9+
* **Groq API Key**: Required for STT and LLM services (Get it for free at [console.groq.com](https://console.groq.com))
* Active Internet Connection

## Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/ballotti07/adam-ai-suite.git
cd adam-ai-suite
```

---

## Option A — Install ONLY the Editor (Adam Creator Pro)

Create a virtual environment, install lightweight dependencies, and launch:

```bash
python -m venv venv-creator

# Windows
venv-creator\Scripts\activate

# Linux/Mac
source venv-creator/bin/activate

pip install -r requirements-creator.txt
python editor/src/main.py
```

## How to Use the Editor

Once the graphical interface opens, follow these steps:

### Design Your Avatar

Use the left sidebar to select avatar parts (Hair, Eyes, Lips, Glasses) and the bottom palette to change colors.

### Save the Profile

Click **SAVE PROFILE** at the top right.

### Configure Personality & Voice

Choose the assistant language (Italian/English), the voice gender (Male/Female), and import a `.txt` file for a custom character prompt.

### Export Files

Save the generated `.json` profile. This file will be used in the Runtime.

---

## Option B — Install the Full Suite (Editor + Runtime)

Create a separate runtime environment and install full dependencies:

```bash
python -m venv venv-adam

# Windows
venv-adam\Scripts\activate

# Linux/Mac
source venv-adam/bin/activate

pip install -r requirements-adam.txt
```

---

## Starting Backend Services

This version of Adam AI uses **Groq Cloud API** for LLM and STT, and **Edge-TTS** for voice generation. 

**No local Docker or WSL services are required.** Simply ensure your `GROQ_API_KEY` is configured in your environment variables or in the `.env` file within the `runtime/` folder.

---

## Running Adam AI (Runtime)

Ensure your environment is active and the assets are unzipped in the project folder:

```bash
# Activate runtime environment first
python runtime/main.py --profile path/to/your/profile.json
```

### Quick Commands

*   **SPACE** → Mute / Unmute microphone
*   **RESET Enter key** → Clear conversation memory
*   **LANG MENU (UI)** → Switch between Italian and English in real-time
*   **ESC** → Close application
